KASPER TOH WEBSITE - HOW TO EDIT (no coding needed)

FOLDERS
  index.html          page text (headline, selling steps, about, contact)
  css/styles.css      colours, fonts and layout
  js/script.js        builds the cards and the WhatsApp form
  data/properties.csv your portfolio
  data/videos.csv     your videos
  assets/photos/      hero.jpg, about.jpg and all property/cover photos
  assets/videos/      your .mp4 video files

ADD A PROPERTY
  1. Put the photo in assets/photos/ .
  2. Open data/properties.csv, add one row, type the photo file name in the "photo" column.
  The first row is shown as the large feature card.

ADD A VIDEO
  1. Put the .mp4 in assets/videos/ and a cover image in assets/photos/.
  2. Add a row in data/videos.csv. In the "file" column you can also paste a
     YouTube / Instagram / TikTok link instead of an .mp4 file name.
